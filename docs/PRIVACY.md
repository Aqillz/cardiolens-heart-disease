# Privacy

The prediction form and Heart Health Assistant run entirely in the browser. Enter only fictional clinical inputs and keep chat messages general.

| Data | Handling |
| --- | --- |
| Prediction values and scores | Kept in the page while it is open. The site makes no requests during calculation and writes no values to browser storage. Clear the form or reload the page to reset it. |
| Questions and answers | Kept in the open page. Clear the chat or reload to remove the conversation. Answers come from bundled rules and source links. |
| Website traffic | The host receives standard requests for static files and may retain ordinary access logs. The site adds no analytics, tracking scripts, or sign-in. |
| Source links | Following a link opens an external site. Those sites have their own privacy policies. |
| Study data | Published files use aggregate results, fitted model parameters, and fictional examples. Individual study rows, row-level SHAP visualizations, the original notebook outputs, and personal academic documents are excluded. |

The results summarize individual SHAP effects across records or show aggregate dependence bins. The Prediction lab demonstrates a local explanation using fictional data entered by the visitor.
